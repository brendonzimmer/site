## Finding a seat, without refreshing all day

When a course is full, an open seat can disappear quickly. USC Course Notifier checks course availability and sends a text message when a seat opens, so students do not have to keep checking by hand.

## Built around a small, useful loop

The project brings together TypeScript, the USC API, Google Cloud, and Twilio. It checks availability, detects an opening, and sends a notification.

Playwright was part of the exploration of USC's registration flow. The project sits at the intersection of browser automation, backend services, and a very practical student problem.

## The stack

- TypeScript
- USC API and Playwright
- Google Cloud
- Twilio notifications
